# 场景配方（Scene Recipes）

八种经过验证的场景原型，构成约 26 秒的产品宣传叙事。每种配方给出目的、图形结构、关键元素与动画节拍。按产品能力挑选，再按品牌重命名与重新配色。

> 所有图形都是 HTML `<div>` / 内联 SVG，配合 §6 定义的配色 token。绝不使用外部图片（logo 除外），绝不用 emoji。

---

## S1 — 品牌开场（~2.6s）

**目的：** 即时建立品牌识别。Logo + 产品名 + 标语。

**图形：** 居中的 logo，环绕轨道粒子，品牌名之下是渐变文字标语。

**元素：**
- `.brand-logo` — logo 图片（120–160px），带发光
- `.orbit` — 2–3 个同心环，内含沿 `motionPath` 或简单旋转运行的小点
- `.brand-name` — 大号渐变文字（品牌 → 辅助色）
- `.brand-tagline` — 柔和副标题
- `.hero-chips` — 3–4 个能力 chip（可选）

**动画节拍：**
1. `t=0.1` logo 弹入（`back.out(1.7)`, scale .8→1）
2. `t=0.4` 轨道环淡入 + 持续旋转（`repeat: -1`，但**受时间限制**）
3. `t=0.5` 品牌名逐行显现（`y: 30→0`）
4. `t=0.9` 标语淡入
5. `t=1.4` chips 错峰进入
6. `t=2.1` `hideScene('s1')`

---

## S2 — 核心编辑器 / 能力（~3.4s）

**目的：** 呈现产品的首要功能——"它是做什么的"。

**图形：** 一个模拟界面（编辑器画布、表格或文档）在真实地填充内容。

**元素：**
- `.editor-frame` — 窗口外框，含 `.titlebar`（红黄绿点）+ `.toolbar`（图标按钮）
- `.editor-canvas` — 内容区：文本行、`<table class="data-table">`、或卡片
- `.typing-line` — 由打字机逐字填入的行
- `.cursor-blink` — 闪烁的插入符

**动画节拍：**
1. 外框滑入 + 工具栏图标错峰
2. 打字机填入标题行（`typeText`）
3. 表格行错峰出现；单元格数字滚动
4. 工具栏图标"被点击"（缩放脉冲）并触发高亮
5. 副标题 chip 随每个能力点亮

> **表格提示：** 使用语义化 `<table class="data-table">` 配 `th`/`td`。在 stacked 模式中以 `.data-table th/td` 增高，而**非** `.tc`/`.tr` 类（那些并不存在 → 死选择器）。

---

## S3 — 搭建 / 创造（~3.4s）

**目的：** 招牌"惊艳"工作流——用户如何创造/搭建。常见于拖拽式搭建器。

**图形：** 一块组件面板 + 一个画布；一张卡片被拖入并吸附到位。

**元素：**
- `.palette` — 左栏可拖拽组件（每块带图标）
- `.canvas` — 放置区，带虚线 `.drop-zone`
- `.drag-card` — 被光标搬运动的卡片
- `.cursor` — 一个指针 SVG，沿路径移动

**动画节拍：**
1. 面板项错峰进入
2. 光标移到某个面板项，按下（缩放脉冲）
3. 光标把 `.drag-card` 拖到 `.drop-zone`（`x/y` 补间）
4. 放置区高亮 → 卡片以 `back.out` 吸附
5. 已搭建的结构逐块累积

---

## S4 — 多维视图 / 灵活性（~3.4s）

**目的：** 展示同一份数据的多种呈现方式（表格 / 看板 / 日历 / 图表）。

**图形：** 带标签的视图切换器，在各可视化形态之间交叉淡入淡出。

**元素：**
- `.view-tabs` — 标签按钮（Table / Kanban / Calendar / Chart）
- `.view-panel` — 每种视图一个，叠放，仅激活的可见
- `.kanban-col`、`.cal-cell`、`.bar` 等，按视图而定

**动画节拍：**
1. 标签栏滑入；第一个视图激活
2. 一个标签"被点击" → 当前视图淡出（`opacity/scale`），下一视图淡入
3. 每种视图展示其招牌动作（看板卡入列、柱状图长高、日历填格）
4. 循环或依次走完各视图

---

## S5 — 生态 / 集成（~3.4s）

**目的：** 展示产品如何接入更广阔的生态（中心辐射式）。

**图形：** 中心 logo/hub，卫星节点连以描边绘制的线条。

**元素：**
- `.hub` — 居中的 logo 或主节点
- `.spoke-node` — 6–8 个环绕的集成点（图标 + 标签）
- `.spoke-line` — hub 到各节点的 SVG `<line>`/`<path>`

**动画节拍：**
1. hub 缩放弹入
2. 连线从中心向外描边绘制（`strokeDashoffset`）
3. 卫星节点在连线抵达时以 `back.out` 错峰弹入
4. 柔和的持续漂浮（受时间限制）
5. 数据"脉冲"沿某几条线跑动（小圆点位移）

---

## S6 — AI 智能（~3.2s）

**目的：** 呈现 AI/自动化能力——查询进，洞察出。

**图形：** 一个提示输入框，随后生成的回答/建议卡片。

**元素：**
- `.ai-prompt` — 输入框，由打字机填入一条问题
- `.ai-thinking` — 闪烁的点或旋转的环
- `.ai-result` — 生成的卡片/摘要/图表
- `.ai-suggest` — 后续建议 chip

**动画节拍：**
1. 提示逐字打入
2. "思考"指示器脉动（约 0.6s）
3. 结果卡片错峰揭示；关键数字滚动
4. 建议 chip 弹入
5. 一个"置信度"环形图填充

---

## S7 — 实时协同（~3.0s）

**目的：** 展示多用户实时协作。

**图形：** 共享画布上出现多个带名字的光标、评论气泡与在线头像。

**元素：**
- `.collab-cursor` — 带名字标签的彩色指针（每个用户一种品牌色）
- `.comment-bubble` — 弹出的评论气泡
- `.avatar-stack` — 在线用户头像（重叠圆圈）
- `.presence-ring` — 头像上的绿点

**动画节拍：**
1. 头像堆叠弹入，在线指示灯点亮
2. 2–3 个彩色光标在画布上各自移动
3. 评论气泡在某光标处弹出
4. 一段文本被"某用户"高亮选中
5. 一个表情/点赞短暂浮现

---

## S8 — 品牌收尾（~3.8s）

**目的：** 以强品牌印象 + CTA 收束。

**图形：** 居中 logo（呼吸态）、标语、能力 chip 行、CTA 按钮与 URL。

**元素：**
- `.outro-logo` — logo，带柔和的 `scale` 呼吸
- `.outro-tagline` — 大字标语
- `.outro-chips` — 汇总各能力的 chip 行
- `.cta-btn` — "立即体验" 按钮（受 CTA 开关控制）
- `.cta-url` — 产品网址

**动画节拍：**
1. logo 缩放入场，随后呼吸（`yoyo`, `sine.inOut`）
2. 标语逐行显现
3. chips 错峰进入
4. CTA 按钮脉冲发光；URL 淡入
5. 光晕柔和收束；**计算真实结束点 → 设置 `DURATION`**

> **CTA 开关：** 右上角的 `#cta-toggle`（`role="switch"`）切换 `.cta-btn` 与 `.cta-url` 的可见性，快捷键 `C`。偏好存入 localStorage。

---

## 跨产品类型适配

这些原型面向多维表格产品提炼，但可迁移：

- **文档 / 编辑器类**（协同文档、写作工具）：S2 = 写作画布；S3 = 模板 / 区块搭建；S4 = 大纲 / 页面 / PDF 视图；S6 = AI 续写；S7 = 实时共同编辑。
- **知识库 / Wiki**：S2 = 搜索 + 文章；S3 = 用 AI 构建知识图谱；S5 = 互联页面；S6 = 问答式检索。
- **仪表盘 / BI**：S2 = 图表构建器；S4 = 图表类型切换；S6 = 自动洞察。
- **非产品（活动/理念）**：把"能力"换成"信息"；S2–S7 成为论据/叙事节拍；保持 S1 开场与 S8 CTA 收尾。

始终：先匹配场景与简介中的能力，再按叙事逻辑排序（问题 → 能力 → 生态 → 智能 → 协作 → 品牌）。
